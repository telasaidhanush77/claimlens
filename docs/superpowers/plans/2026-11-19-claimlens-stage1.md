# ClaimLens Stage 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upload a health-policy PDF, get its claim-deciding terms with verified page quotes, enter a hospital estimate, and see a line-by-line claim simulation plus a room-choice comparison, on one live URL.

**Architecture:** FastAPI back end; a pure-Python claim engine does all arithmetic; the LLM only extracts typed terms from pgvector-retrieved chunks, and each quote is checked against the PDF text. A Next.js static export is served by FastAPI from the same Docker image.

**Tech Stack:** Python 3.12, FastAPI, psycopg 3 + psycopg-pool, Postgres 16 + pgvector, pypdf, httpx (Gemini `gemini-embedding-001` + `gemini-3.5-flash-lite`, Groq `openai/gpt-oss-120b` fallback), fpdf2 (dev, sample PDF), Next.js (TypeScript, Tailwind, `output: 'export'`), Docker, Render, Neon.

**Spec:** `docs/superpowers/specs/2026-11-19-claimlens-design.md`

## Global Constraints

- The LLM never computes money. All amounts come from `app/engine.py`.
- A term is `verified=True` only if its quote is found in the PDF text; otherwise its value is discarded (`value=None`) and the UI asks the user to enter it.
- Money is `Decimal`; final insurer/you-pay figures round half-up to whole rupees.
- Every result screen shows: "Estimate only, not insurance advice. Check the quoted clauses."
- No real patient data in the repo. Sample bills are synthetic; the bundled sample policy is generated by our own script.
- Free tiers only. `DEMO_MODE=1` serves the sample policy from a committed cache, using no API calls.
- Python lint: ruff, line length 100. Tests: pytest. Local DB: docker `pgvector/pgvector:pg16` on port **5434**.

## Review Focus

1. A room limit written as "1% of Sum Insured per day" vs "₹5,000 per day": both must produce the same engine behaviour. Covered in Task 1 tests.
2. A quote whose whitespace, case, line breaks or page differs from the PDF text must still verify; a quote that isn't in the PDF must not. Covered in Task 3.
3. A scanned PDF with no text layer: return 422 "This PDF has no text layer (scanned). Upload the text version of your policy wording." Do not call the LLM. Covered in Task 7.
4. An LLM reply that is not JSON, or a quota error from both providers: upload returns 502 "Couldn't read the policy right now, try again in a minute." Per-term junk only marks that term unverified. Covered in Tasks 5 and 7.
5. A policy with no room limit: no proportionate deduction, and room charges fully payable. Covered in Task 1.

### Task 1: Scaffold + claim engine

**Files:**
- Create: `pyproject.toml`, `.gitignore`, `app/__init__.py`, `app/models.py`, `app/engine.py`, `tests/test_engine.py`

**Interfaces:**
- Produces (`app/models.py`, Pydantic v2):
  - `Category = Literal["room","icu","surgeon","ot","diagnostics","medicines","consumables","implants","other"]`
  - `Term[T](value: T | None, page: int | None, quote: str | None, verified: bool = False)` (a generic model)
  - `Limit(kind: Literal["per_day","pct_si"], amount: Decimal)` (amount in ₹ for `per_day`, percent for `pct_si`)
  - `PolicyTerms(sum_insured: Term[Decimal], room_limit: Term[Limit], icu_limit: Term[Limit], proportionate: Term[bool], proportionate_categories: Term[list[Category]], copay_pct: Term[Decimal], deductible: Term[Decimal], sublimits: Term[dict[str, Decimal]], non_payable: Term[list[Category]])`
  - `LineItem(description: str, category: Category, amount: Decimal (>0), days: int | None (>=1, required when category is room or icu))`
  - `Estimate(procedure: str | None, items: list[LineItem] (min 1), room_options: list[RoomOption] = [])` with `RoomOption(name: str, rate_per_day: Decimal (>0))`
  - `LineResult(description, category, billed: Decimal, payable: Decimal, notes: list[str])`
  - `Step(label: str, total_after: Decimal, page: int | None)`
  - `Simulation(lines: list[LineResult], steps: list[Step], billed: int, insurer_pays: int, you_pay: int)`
- Produces (`app/engine.py`): `simulate(terms: PolicyTerms, est: Estimate) -> Simulation`, `limit_per_day(limit: Limit, sum_insured: Decimal | None) -> Decimal | None`

Use only the `.value` of verified-or-user-entered terms (a `None` value means "not in the policy"). Order of application, each producing a `Step`:
1. Non-payable categories → payable 0, note "Not payable (p.N)".
2. Room / ICU: payable = min(rate, limit) × days, with rate = amount / days.
3. Proportionate deduction: if `proportionate` is true and the room rate is above the room limit, ratio = limit / rate; lines whose category is in `proportionate_categories` get payable × ratio, note "Cut to NN% because the room is above your limit (p.N)".
4. Sub-limit: if `est.procedure` is a key in `sublimits`, the total is capped at it.
5. Deductible subtracted (floor 0). 6. Co-pay: total × (1 − pct/100). 7. Cap at sum insured.

### Task 3: PDF text + quote verification

**Files:** Create `app/pdf.py`; Test `tests/test_pdf.py`, `tests/fixtures/` (tiny PDF generated in the test with fpdf2)

**Interfaces:**
- Produces `read_pages(data: bytes) -> list[str]` (index 0 = page 1; raises `NoTextLayer` when the total stripped text has fewer than 200 chars) and `class NoTextLayer(Exception)`.
- `normalize(s: str) -> str`: lowercase, join hyphenated line breaks (`-\n` → ``), collapse whitespace, map `₹`/`Rs.`/`INR` to `rs`, and drop commas inside numbers.
- `locate_quote(pages: list[str], quote: str, page_hint: int | None) -> int | None`: returns the 1-based page containing the normalized quote. Try the hint first, then hint ± 1, then all pages. Quotes shorter than 12 normalized chars return None. A quote spanning a page break is matched against each page joined with the next.

### Task 4: Database, chunks, embeddings, retrieval

**Files:** Create `app/config.py`, `app/db.py`, `app/embed.py`, `app/retrieve.py`, `migrations/001_init.sql`, `docker-compose.yml`, `tests/conftest.py`, `tests/test_retrieve.py`

**Interfaces:**
- `Settings` (env): `DATABASE_URL`, `TEST_DATABASE_URL`, `GEMINI_API_KEY`, `GROQ_API_KEY`, `GEMINI_MODEL="gemini-3.5-flash-lite"`, `GROQ_MODEL="openai/gpt-oss-120b"`, `EMBED_MODEL="gemini-embedding-001"`, `EMBED_DIM=768`, `DEMO_MODE=False`.
- Schema: `CREATE EXTENSION IF NOT EXISTS vector;` `policies(id uuid pk default gen_random_uuid(), name text, pages jsonb not null, terms jsonb not null, created_at timestamptz default now())`; `chunks(policy_id uuid references policies on delete cascade, page int, ord int, text text, embedding vector(768))` with an HNSW cosine index.
- `db.pool(settings) -> ConnectionPool`; `db.migrate(pool)` runs `migrations/*.sql` in order (idempotent).
- `embed.Embedder` protocol: `embed(texts: list[str], task: Literal["doc","query"]) -> list[list[float]]`. `GeminiEmbedder` uses `batchEmbedContents` with `outputDimensionality=768` and taskType `RETRIEVAL_DOCUMENT`/`RETRIEVAL_QUERY`, in batches of 100. `FakeEmbedder` (tests) uses deterministic hashed bag-of-words vectors.
- `retrieve.chunk(pages) -> list[tuple[int, int, str]]`: about 2,000-char chunks with a 250-char overlap, never crossing a page.
- `retrieve.store(pool, policy_id, pages, embedder)`.
- `retrieve.search(pool, policy_id, query, embedder, k=4) -> list[tuple[int, str]]` returns (page, text).
- Vectors are sent as the text literal `'[..]'::vector` (no pgvector Python dependency).

### Task 5: LLM client + term extraction

**Files:** Create `app/llm.py`, `app/extract.py`; Test `tests/test_extract.py`

**Interfaces:**
- `llm.LLM` protocol: `json(prompt: str) -> dict` (raises `LLMError`). `GeminiLLM` (`responseMimeType: application/json`, temperature 0) and `GroqLLM` (`response_format: json_object`). `FallbackLLM(primary, secondary)`. Retries on 429/5xx, honouring Retry-After capped at 30 s, max 3 tries; other 4xx fail at once.
- `extract.TERM_QUERIES: dict[str, str]`: one retrieval query per `PolicyTerms` field, e.g. `room_limit → "room rent limit per day normal room category"`.
- `extract.extract_terms(pages, retrieved: dict[str, list[tuple[int,str]]], llm) -> PolicyTerms`. Retrieved chunks from all fields are de-duplicated into one prompt, so it's **one LLM call**. The prompt asks for JSON `{field: {"value": ..., "page": int, "quote": "<verbatim sentence>"} | null}` with the value shapes spelled out (`Limit` as `{"kind","amount"}`, categories from the `Category` list only). Each field is parsed with Pydantic; then `locate_quote` sets `verified` and corrects `page`; an unverified field gets `value=None`. A field that fails parsing → `Term(value=None, verified=False)`.
- `extract.read_policy(pool, name, data: bytes, embedder, llm) -> tuple[UUID, PolicyTerms]`: read_pages → insert policy → store chunks → search per field → extract → save terms.

### Task 7: HTTP API

**Files:** Create `app/main.py`; Test `tests/test_api.py`

**Interfaces (all JSON; errors as `{"detail": str}`):**
- `GET /healthz` → `{"ok": true}`
- `POST /api/policies` (multipart `file`, PDF ≤ 15 MB, else 413) → `{"id", "name", "terms": PolicyTerms}`. `NoTextLayer` → 422 with the Review Focus copy; `LLMError` → 502 with the Review Focus copy; no LLM keys and not demo → 503 "Live policy reading is off on this server; try the sample policy."
- `POST /api/policies/sample` → the sample, inserted from `terms.json` (no LLM, no embeddings needed).
- `GET /api/policies/{id}` → same shape; 404 if missing.
- `PUT /api/policies/{id}/terms` (body `PolicyTerms`) → saves user-entered values. A term the user filled in has `verified=False, quote=None` and is labelled "entered by you" in the UI.
- `POST /api/simulate` (`{"policy_id", "estimate": Estimate}`) → `Simulation`; 422 on invalid estimate.
- `GET /api/sample-estimate` → `estimate.json`
- Static: mount `web/out` at `/` when it exists.
- Dependencies (pool, embedder, llm) via FastAPI `Depends`, overridable in tests.
